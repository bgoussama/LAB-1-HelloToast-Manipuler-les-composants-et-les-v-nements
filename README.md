## 🎯 Objectif du projet

Créer une petite application Android qui permet :
- d’afficher un message **Toast**
- d’incrémenter un **compteur**
- d’interagir avec deux boutons

Ce projet est réalisé avec :
- Java
- Android Studio
- API minimum : 24 (Android 7.0)

---

## 🧩 Fonctionnalités

### 1. Affichage d’un Toast
Lorsque l’utilisateur clique sur le bouton **"Afficher un message"**, une notification temporaire s’affiche à l’écran.

### 2. Compteur dynamique
Lorsque l’utilisateur clique sur le bouton **"Incrémenter le compteur"**, la valeur affichée augmente de 1.

---

## 📸 Interface utilisateur (UI)

L’interface contient :
- Un `TextView` pour afficher le compteur
- Un bouton pour afficher un Toast
- Un bouton pour incrémenter le compteur

---

## 🧠 Logique de l’application

- Gestion des clics avec `setOnClickListener()`
- Mise à jour de l’interface avec `setText()`
- Affichage de message avec `Toast.makeText()`
