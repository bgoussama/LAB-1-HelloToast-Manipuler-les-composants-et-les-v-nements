# Hello Toast App

Ceci est le premier Lab Android. L'application affiche un compteur qui peut être incrémenté et un bouton pour afficher un message Toast.

## Démonstration
[Insérer la vidéo de démonstration ici]

## Fonctionnalités
- **Bouton TOAST** : Affiche un message "Hello Toast!" à l'écran.
- **Bouton COUNT** : Incrémente le compteur affiché au centre.
- **Interface** : Utilise un `ConstraintLayout` avec des couleurs personnalisées pour correspondre à la maquette.
